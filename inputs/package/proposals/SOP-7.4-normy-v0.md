# Пропозиція до SOP-7.4: норми навантаження v0

| Одиниця | Стандарт часу | Основа |
|---|---|---|
| Вхідний дзвінок | 4.5 хв | розмова ~3.0 хв (факт) + обробка 1.5 хв (припущення) |
| Вихідний дзвінок з розмовою | 2.5 хв | ~1.5 (факт) + 1.0 (припущення) |
| Вихідна спроба без відповіді | 0.5 хв | припущення |
| Вихідний лист | 4 хв | припущення |
| Вхідний лист (розбір) | 0.5 хв | припущення |
| Створення ордера | 10 хв | припущення |

| | 8-год зміна | 9-год | 7-год |
|---|---|---|---|
| Продуктивний час (−25%) | 360 хв | 405 | 315 |
| **Норма (85%)** | **300 хв** | **340** | **270** |

Зони: <150 систематично — перевірити, куди йде час; 150–300 — норма; 300–340 — епізодично допустимо; >340 два тижні поспіль — перерозподіл або найм.

**Факт (12 тижнів):** видиме в HubSpot навантаження команди ~75 год на тиждень (~21% оплаченого часу за умови повних ставок). Чати Hub, Teams, Telegram не виміряні. Потрібно: фактичний графік змін і 1–2 тижні хронометражу (ManicTime).
