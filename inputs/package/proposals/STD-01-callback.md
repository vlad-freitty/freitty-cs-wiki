# Пропозиція до STD-01: строки зворотного виклику

| Параметр | Значення |
|---|---|
| Спроба 1 | ≤10 хв після втраченого дзвінка |
| Спроба 2 | +1 год після спроби 1; залишити голосове повідомлення |
| Спроба 3 | Наступний робочий день клієнта, в інший час доби, ніж перші дві; якщо є email — лист |
| Закриття | Після 3 невдалих спроб — «Недоступний» |
| Вікно дзвінків | 08:00–20:00 за місцевим часом клієнта |
| Ціль охоплення спробою | 100% втрачених номерів |
| Ціль перших спроб у строк | 80% |
| Ціль результативності | 60% втрачених — з розмовою |
