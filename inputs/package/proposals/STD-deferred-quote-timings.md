# Пропозиція: строки відкладеної квоти

| Параметр | Значення |
|---|---|
| Перший контакт по YELLOW-запиту | ≤10 хв (як в Instant Book CS Guide) |
| Квота транспорту | ≤1 год |
| Квота Rework | ≤30 хв після отримання фото |
| Відповідь хабу (ємність, вага, нічний тариф) | ≤1 год |
| Термін дії квоти | 24 год |
| Нагадування 1 | через 2 год без відповіді |
| Нагадування 2 | через 20 год («квота спливає») |
| Максимум без результату | 48 год |
| Нагадування про фото Rework | через 2 год без фото |
