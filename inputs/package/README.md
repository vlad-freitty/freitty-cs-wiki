# FREITTY CS Operating System

База знань Customer Support Freitty. Джерело правди — цей репозиторій. Сайт — Vercel (лише читання, доступ закритий).

## Як запустити (для Влада)

1. **Експорт з Notion:** сторінка бази CS → ⋯ → Export → Markdown & CSV, з підсторінками. Розпакувати в `import/notion/`.
2. **Репозиторій:** створити приватний репозиторій на GitHub, покласти туди вміст цього пакета, `git push`.
3. **Claude Code:** у папці репозиторію запустити `claude` і виконувати кроки з `PROMPTS.md` по одному.
4. **Vercel:** New Project → імпорт репозиторію → **увімкнути захист доступу до першого поширення посилання**.

## Що всередині
- `CLAUDE.md` — ТЗ для Claude Code
- `PROMPTS.md` — кроки
- `registry/` — реєстр v1.58 і легенда
- `docs/` — готові документи з дизайну (SOP-1.7, SOP-2.6)
- `proposals/` — пропозиції змін до існуючих документів
- `analytics/` — знімок даних
- `decisions/` — журнал рішень
- `core.yaml` — Ядро v1
