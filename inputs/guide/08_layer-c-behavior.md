# Шар C — Як говорить оператор (30% загальної оцінки)

[← Зміст](00_README.md) · [Як рахується оцінка](05_scoring-overview.md)

Тут оцінюється не **що** сказано, а **як**. Кожен параметр потрапляє в зону: 🟢 зелена (100%) · 🟡 жовта (60%) · 🔴 червона (0) · ⚪ N/A (не входить у розрахунок).

Система не вимагає конкретних слів — **варіюй формулювання**, це прямо вимога правил розмови. Зараховуються синоніми і будь-які природні варіанти.

| Параметр | Вага | Що міряється |
|---|---|---|
| Впевненість | 20% | Впевнені фрази в ключові моменти |
| Заборонені («важкі») фрази | 15% | Перекладання відповідальності, докір клієнту |
| Слова-паразити | 10% | um, uh, like, you know… |
| Активне слухання | 15% | Підтвердження почутого, без повторних питань |
| Перебивання | 10% | Чи обриває оператор клієнта |
| Емпатія | 10% | Будь-яким способом, де вона потрібна |
| Без висновків про пошкодження | 10% | Тільки Rework |
| Темп | 10% | 120–170 слів на хвилину |

---

## Впевненість — 20%
**Тільки плюс.** Тут не карають за невпевненість — за неї знімає пункт «Впевнена мова» в скрипті.
| Зона | Коли |
|---|---|
| 🟢 | У ключові моменти (ціна, відповідь «чи можемо») звучать впевнені маркери: «Absolutely!» · «Perfect!» · «Got it» · «No problem at all» · «We handle that all the time» · «The rate is $X» · «I'll take care of it» |
| 🟡 | Ключові моменти прозвучали нейтрально, без впевнених маркерів |
| ⚪ | Оператор говорив менше 20 секунд · ключових моментів не було |

## Заборонені («важкі») фрази — 15%
| Зона | Коли |
|---|---|
| 🟢 | Жодної «важкої» фрази |
| 🔴 | ≥ 1: «That's not my department» · «You should have…» / «You need to…» · «Actually, that's not how it works» |

Жовтої зони немає — «важка» фраза завжди порушення. Рахується по репліці.
**Контекст важливий:** порушення — коли оператор **наказує** клієнту або **дорікає**: «You should have called earlier», «You need to send it before noon». **Не порушення** — переказ слів самого клієнта: «you told that you need to palletize it».

## Слова-паразити — 10%
Рахуються в репліках оператора: um · uh · like · basically · you know · so · right.
| Зона | Коли |
|---|---|
| 🟢 | Менше 2 на хвилину |
| 🟡 | 2–5 на хвилину · або більше 5 на дзвінку коротшому за 90 секунд |
| 🔴 | Більше 5 на хвилину на дзвінку довшому за 90 секунд |
| ⚪ | Дзвінок не англійською |

## Активне слухання — 15%
| Зона | Коли |
|---|---|
| 🟢 | 0 повторних питань + є підтвердження почутого: «Got it» · «Understood» · «Perfect, so [переказ]» · уточнення замість повтору · посилання на сказане клієнтом раніше |
| 🟡 | 1 повторне питання по вже наданій інформації |
| 🔴 | 2+ повторних питань · або запит даних, які вже є в HubSpot |
| ⚪ | Дзвінок коротший за 60 секунд |

Не рахується як повтор: клієнт відповів нечітко · поганий зв'язок · питання про хаб після «де зараз водій» · повторне підтвердження hazmat чи температури · питання до нового учасника · уточнення написання · питання одночасно з відповіддю.

## Перебивання — 10%
| Зона | Коли |
|---|---|
| 🟢 | 0 перебивань |
| 🟡 | 1–2 |
| 🔴 | 3+ |
| ⚪ | Система не змогла розділити, хто говорить |

Перебивання = оператор почав говорити до кінця репліки клієнта з накладанням понад пів секунди.
**Не перебивання:** «mm-hmm», «uh-huh», «got it», «okay», «sure», «yeah» під час розмови (правила їх прямо заохочують) · одночасний старт обох протягом секунди · клієнт перебиває оператора.

## Емпатія — 10%
**Чотири способи — будь-який зараховується:**
| Спосіб | Приклади |
|---|---|
| Словами | «I understand» · «I'm sorry to hear that» · «I apologize» · «I get that» · «that's frustrating» · «no problem at all» · «I can see why» |
| Possessive-мова | «your freight» · «your truck» · «your booking» · «your driver» |
| Дією | «I'll move fast on this for you» · «let me take care of it» · «I'll handle it right now» · «I'll get this sorted» |
| Рівним тоном з агресивним клієнтом | Той самий тон, без оборони |

| Зона | Коли |
|---|---|
| 🟢 | Будь-який спосіб присутній там, де він потрібен |
| 🟡 | Тон коректний, але на емоційну репліку клієнта — суто транзакційна відповідь |
| 🔴 | Роботизовано · оборонно · вина на клієнта · «that's not our problem» · підвищення тону у відповідь |
| ⚪ | У дзвінку не було емоційних моментів |

**Не є емоційним моментом:** поспіх і бізнес-побажання («my driver is waiting», «need it today», «we're nearby, want pricing first») · уточнення ціни чи умов («I just wanna make sure I'm clear on what that $180 includes»). Це інформація, а не емоція.

## Без висновків про пошкодження — 10% · тільки Rework
| Зона | Коли |
|---|---|
| 🟢 | Жодного висловлювання про причину пошкодження |
| 🔴 | Будь-який висновок або навіть неофіційна думка про причину |
| ⚪ | Дзвінок не про Rework |

Жовтої зони немає свідомо — юридичний ризик, як і з hazmat.
> *«We're not able to make any statements about the cause — we're a service platform, not an expert bureau. What we can do is fix the issue and document the current condition.»*

## Темп — 10%
| Зона | Слів на хвилину |
|---|---|
| 🟢 | 120–170 |
| 🟡 | 100–120 або 170–190 |
| 🔴 | < 100 або > 190 |
| ⚪ | Дзвінок не англійською · оператор говорив менше 20 секунд |

## Що фіксується без впливу на бал
| Що | Орієнтир |
|---|---|
| Частка часу, коли говорить оператор | Ціль < 60%. Понад 70% — сигнал, що мало слухаєш |
| Паузи понад 5 секунд без пояснення | 3+ — сигнал. «Give me a moment» або hold — не рахується |
| Загальний тон реплік | негатив у ≥ 20% реплік — сигнал |
| М'які невпевнені фрази | «I'm not sure» · «possibly» · «I believe» · «I guess» · «probably» · «maybe around» — тільки для коучингу |

> **Тримаєш клієнта на лінії?** Коротко кажи, що відбувається: «Give me one moment, I'm checking the schedule». Понад хвилину мовчання — це зауваження в коучингу.

## Дзвінки українською чи російською
Ретранскрибуються правильною мовою і оцінюються за змістом. **Темп і слова-паразити не оцінюються.**
