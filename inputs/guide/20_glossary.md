## Система і процес
| Термін | Що означає |
|---|---|
| **CAE** (Call Audit Engine) | AI-аналізатор дзвінків |
| **QA-нотатка** | Результат аналізу, який система додає до дзвінка в HubSpot |
| **Транскрипт** | Текст розмови з Dialpad |
| **Ретранскрибація** | Повторне розпізнавання дзвінка правильною мовою (для української/російської або нерозбірливих записів) |
| **Діаризація** | Розділення транскрипту на репліки оператора і клієнта |
| **Шар A / B / C** | Три частини оцінки: CRM / скрипт / манера розмови |
| **Загальна оцінка** (composite) | A × 30% + B × 40% + C × 30% |
| **Чекпоінт** (cp) | Пункт чекліста скрипту |
| **PASS / PARTIAL / FAIL / N/A** | Виконано / частково (50%) / не виконано / не застосовується |
| **Зелена / жовта / червона зона** | Оцінка манери розмови: 100% / 60% / 0 |
| **Родина кваліфікацій** | Близькі типи, розбіжність між якими дає 50%, а не 0 |
| **Сигнал / аномалія** | Ситуація, на яку керівнику варто відреагувати |
| **P0 / P1 / P2** | Терміновість сигналу: одразу / за зміну / за тиждень |
| **Confidence** | Наскільки AI впевнений у своїй кваліфікації |
| **Версія оцінки** (scoring_version) | Номер набору правил. Оцінки різних версій не порівнюються |
| **T+30** | Момент через 30 хвилин після дзвінка, коли система читає HubSpot |
| **Регресійний набір** | Реальні спірні дзвінки, на яких перевіряють кожне оновлення |
| **Тег команди** | Команда оператора в аналізаторі (зараз активна КС). Без тегу дзвінки транскрибуються, але не оцінюються |

## Логістика
| Термін | Що означає |
|---|---|
| **Cross-Dock** | Перевантаження вантажу через хаб без тривалого зберігання |
| **Deconsolidation** | Розформування збірного вантажу |
| **Storage** | Короткострокове зберігання |
| **Overweight Help** | Допомога з перевантаженим траком |
| **Rework / Restack** | Переробка / перестановка пошкодженого чи неправильно завантаженого вантажу |
| **Drayage** | Перевезення контейнерів на коротку відстань (порт / залізниця) |
| **Middle Mile** | Перевезення між логістичними вузлами |
| **Floor Load** | Вантаж насипом, без палет |
| **FAK** | Freight All Kinds — змішаний звичайний вантаж |
| **BOL** | Bill of Lading — накладна |
| **MC / DOT** | Реєстраційні номери перевізника / брокера в США |
| **SAFER** | Державна база FMCSA, де за MC видно: carrier чи broker, активний чи ні |
| **Shipper** | Вантажовідправник (власник вантажу) |
| **Carrier** | Перевізник |
| **Broker** | Посередник між shipper і carrier |
| **Owner-operator** | Водій-власник свого трака, працює як перевізник |
| **Dispatcher** | Диспетчер перевізника |
| **Hazmat** | Небезпечні вантажі (класи 1–9 за 49 CFR) |
| **49 CFR** | Федеральні правила США щодо перевезення небезпечних вантажів |
| **Reefer** | Рефрижератор, вантаж з температурним режимом |
| **FR#** | Номер ордера Freitty |
| **InstaBook / Instant Book** | Онлайн-бронювання на freitty.com |
| **YELLOW** | Статус онлайн-заявки, яка потребує уточнення оператором |
| **Complimentary hub** | Партнерська локація в мережі Freitty |
| **Gate code** | Код для в'їзду на територію хабу |
| **Check-in номер** | Номер для реєстрації водія на хабі |
| **Trojan Horse** | Брокер, який представляється клієнтом; також — фоновий процес їх виявлення |
| **Rejected By Us** | Статус угоди, коли Freitty відмовив через невідповідність даних |
