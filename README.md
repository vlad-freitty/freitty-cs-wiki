# Freitty CS Wiki

База знань Customer Support Freitty: політики, процедури, реєстр документів, інструменти, довідник, ролі, журнал ознайомлень (REG-13), архів версій і позначки до пунктів.

**Сайт:** приватна сторінка на claude.ai — https://claude.ai/artifact/2d71rDBWh1Qb4b3zQ6sAcw
Доступ дає власник через Share: команді — **Contributor** (читати, відмічати ознайомлення, ставити позначки), Head of CS — **Editor** (журнал, призначення, відповіді на позначки).

**Джерело правди — цей репозиторій** (рішення 6.2 журналу рішень). Сайт — лише представлення. Дані, які створює сама команда (ознайомлення, призначення, позначки, журнал), живуть у базі сторінки на claude.ai і в репозиторій не потрапляють.

## Структура

| Шлях | Що там |
|---|---|
| `inputs/pdf/` | Документи у PDF, як їх дала Head of CS (POL-01…POL-14, SOP-1.9) |
| `inputs/package/` | Пакет CS-OS: реєстр v1.58, легенда, ядро, журнал рішень, пропозиції, SOP з дизайн-сесії |
| `inputs/legacy/` | Стара вікі v2.0 (інструменти і методологія — вбудовуються як є, перефарбовані) |
| `site/template.html` | Сторінка вікі: дизайн, навігація, пошук, ознайомлення, журнал |
| `site/situations.json` | Навігатор «Що робити, коли…» |
| `site/quiz.json` | Питання перевірки розуміння для Tier 0 (проєкт — на перевірку власникам) |
| `site/extra_docs.json` | Документи, написані для вікі (проєкт POL-21) і нові рядки реєстру (POL-21, REG-13) |
| `tools/` | `parse_pdf.py` → `assemble.py` → `build.py` |
| `data/docs_pdf.json` | Розібраний текст PDF |
| `data/versions/<CODE>/<версія>.json` | **Архів версій.** Кожна версія документа заморожується при першій збірці. Не видаляти (правило №4 реєстру) |
| `data/wiki_data.json` | Зібрані дані для сторінки |
| `dist/freitty-cs-wiki.html` | Готова сторінка, яка публікується |

## Як оновити документ

1. Покласти новий PDF у `inputs/pdf/` під іменем коду (`POL-03.pdf`). Версія береться з паспорта документа: **текст без підняття версії не змінюємо** — `assemble.py` попередить, якщо текст змінився, а номер версії ні.
2. `pip install pymupdf pyyaml`
3. З кореня репозиторію:
   ```
   python -I tools/parse_pdf.py data/docs_pdf.json inputs/pdf/*.pdf
   python -I tools/assemble.py .
   python -I tools/build.py .
   ```
4. Перевірити `dist/freitty-cs-wiki.html`, закомітити разом із новим файлом у `data/versions/`, опублікувати сторінку за тим самим посиланням.

Попередня версія автоматично з'являється в «Архіві версій» з повним текстом і порівнянням по пунктах. Усі, для кого документ обов'язковий, бачать «Вийшла нова версія» і ознайомлюються знову.

Поки що оновлення робить Claude у Claude Code за цим порядком. Інші способи заливати документи (через саму сторінку) — у наступних ітераціях.

## Правила змісту

- Зміст документів не вигадується і не переписується; технічне форматування — можна (CLAUDE.md пакета, правило 7).
- Числа (строки, пороги) — лише в STD.
- Нові документи спершу отримують код у реєстрі.
- Дані клієнтів у вікі не потрапляють — ні в документи, ні в позначки (POL-02).
